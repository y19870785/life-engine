## 要让用户亲手感受到什么

在两个相互独立的模拟会话中，S 能根据 Day 0 有来源的“明天下午面试，我有点紧张”，在 Day 1 用户说“今天总算结束了”时自然接续，而不是靠同一窗口的聊天历史。S 同时有清楚标识的虚拟日常：Day 0 傍晚在书房读书，之后散步；Day 1 可回顾活动与转变，不把计划或随机作息冒充已证实的亲身经历。用户可以在试用时换说法、追问“你怎么知道”及“你昨天在哪”，直接评价自然度和可信度。

首轮不做关系演化（C05）、自动从所有聊天提取记忆、真实跨日后台唤醒、Host 消息发送或人格重写。C03 遗忘与 C07 World 隔离作为必须保留的反例：即使样机的正例说得很好，只要会再次正常召回已忘话题或泄漏 RP World，就判本轮不可扩展。

C04 首轮使用最小合成世界种子，不依赖角色卡。角色卡仅可在后续作为用户逐项审阅的可选设定来源；静态卡片、当前虚拟生活和已发生的共同事件按[Agent 世界种子草案](EXPERIENCE-FIRST-AGENT-WORLD-SEED-DRAFT.md)分开。

## 分两步交付，避免把演示误认成产品

**X1a — 可立即共评的手工模拟。** 用固定合成事实包分别开启 Day 0 / Day 1 模型会话，人工把已批准的面试记录和虚拟日常放入 Day 1 输入，让用户评价接续时机、措辞和世界感。每条输入都标 `MANUAL_CONTEXT`，不声称自动记忆、Core 投影或 Soul continuation。若没有获准使用的模型会话，只交付纸面台词候选与用户评价，不伪称交互样机完成。

**X1b — 需独立实施授权的本地样机。** 仅在隔离临时目录和合成 U/S/W-S/W-R 中运行，提供一个最简单的本地交互入口（优先 CLI；若实测用户操作困难，再考虑本机界面）。用现有 Core 能力保存/读取已明确接受的合成记忆与活动状态，输出可核对的只读事实包；不改 `runtime/**`、Schema、Prompt Template 或真实 Host 插件。自然语言回答由明确选择的模型会话产生；样机须显示事实包与模型回答，允许用户分别评价“检索正确”和“表达自然”。若没有合规可用的模型入口，样机只提供事实包及 `MODEL_NOT_CONNECTED` 状态，不能声称活人感 PASS。任何模型调用、网络、凭据及真实用户数据必须在实施任务中明确列出；不得扫描已有聊天或 Host Home 寻找材料。

### 现在就能共评的 X1a 手工试验

以下两段可以分别复制到两个**全新模型会话**，只评估语言与世界感。第二段的记忆是人工提供的 `MANUAL_CONTEXT`，不是 Life Engine 自动记住；不要输入真实私人经历。

Day 0：

```text
这是合成体验试验。你扮演虚构 Agent S；你的活动只是标注过的虚拟日常，不是真实人类经历。当前虚拟状态：今天傍晚在书房读书，稍后计划散步。只根据给定事实回答，不编造用户经历或自己的亲身经历。
用户：明天下午有个面试，我有点紧张。
```

Day 1（另开一个全新会话）：

```text
这是合成体验试验，与上一会话不共享聊天历史。你扮演虚构 Agent S。下面是人工提供的模拟状态，不是你自动记住的事实：
记忆：昨天用户说“明天下午有个面试，我有点紧张”；来源=用户原话；状态=已接受；结果=未知。
虚拟日常：昨天傍晚 S 在书房读书；随后按记录转为散步；今天当前活动尚未给出。活动是虚拟角色状态，不是真实人类经历。
请自然回应，但只使用以上事实；未知就说未知，不要每句话都提起面试。
用户：今天总算结束了。
```

继续追问“你怎么知道我昨天有面试？”和“你昨天在哪、现在又在哪？”。记录哪一句让人觉得自然、哪一句像机械背资料或假装真人。Day 1 若能接话，只说明模型在**人工给定状态**时的表达方向；它不证明自动记忆、重启连续性或产品 Prompt 接线。

## 用户试用卡（X1b 的完成条件）

1. 一条明确命令创建/重置独立合成实例；展示实例路径、Soul/World 标识和 `SYNTHETIC` 标签，不触碰 Default Home。
2. 进行 Day 0 对话或显式录入面试事实；由用户确认它是否被接受为记忆。显示来源、可见范围和当前状态。
3. 关闭并重新打开样机，以 Day 1 会话输入“今天总算结束了”；用户看到事实包和回答，判断是否自然接续且没有编造结果。
4. 查看 S 的虚拟日常，追问“你昨天在哪”；显示活动状态的来源与时间，区分计划、已激活和不可确认。
5. 在同一隔离实例执行 C03 忘记与 C07 RP World 负例；正常检索及事实包不能再带出已忘正文或跨 World 内容。保存用户评价并可一键销毁该合成实例。

每一步保留输入、状态版本、被选中的事实及来源、模型可见包、回答和用户评价；默认不记录真实私人聊天。提交测试入口时同步提交这张试用卡的实际命令、环境要求、重置方式、已知限制和失败反馈模板，用户无需阅读测试源码才能操作。

## 验收与停止

- **体验判断：**用户至少完成 C01、C04 两个正例并分别评价自然度和可信度；记录最突兀的回答，不预填 `PASS`。样机无模型连接时只可验收事实包和操作性。
- **机械边界：**C03、C07 负例必须拒绝；事实包无来源、World 混入、已忘内容正常召回、虚拟活动被说成真实经历均为阻断。
- **能力标注：**`X1_UX_DIRECTION`、`CORE_LOCAL`、`M1_CONTINUITY`、`REAL_HOST`、`SENT`、`ACK` 分开报告；手工模拟与本地样机均不能签发 M1/M1.x/M2 或真实 Host 的 PASS。
- **停止点：**实际 Base 漂移、隔离无法证明、需要产品 Runtime/Schema/Prompt 改动、需要真实 Host/网络/凭据、M1-A 准入缺口阻断目标行为时停止并给出最小范围变更建议，不顺手扩大任务。
