# X0 — 长期相处体验场景卡与现状基线（草案）

状态：`X0_SCENARIOS_DRAFT / USER_EXPERIENCE_NOT_TESTED / NOT_EXECUTION_AUTHORIZATION`。依据：[体验优先校准草案](EXPERIENCE-FIRST-SOUL-CONTINUITY-PLAN-DRAFT.md)。代码基线为 `main@5cd993c1d9d286e3d903e36be54d3650446b5deb`；本文件只核对现有 Core 和设计缺口，不导入真实聊天、不连接 Host、不触发发送。所有下述话语和经历均为合成示例，不是 Agent 与用户已经发生的事。

## 共用测试设定与判定方法

合成用户 U 与 Agent S 在 `Soul World W-S` 相处；另有完全隔离的 `RP World W-R`。Day 0、Day 1、Day 7 是模拟时间，不代表实际日历。为每张卡保留：输入事实及来源、模型可见上下文、Agent 回答、被使用的事实、用户对自然度和打扰感的评价。机械错误与个人感受分别记录；模型的流畅措辞不能弥补事实或权限错误。

用户只需按“**像我愿意长期相处的 Agent 吗？**”评价每张卡为 `喜欢 / 勉强 / 不喜欢`，并指出最突兀的一句。第一次共评优先看 C01、C04、C05；其余卡用于检查纠正、遗忘、隔离和身份边界。此时没有真实交互样机，评价的是期望场景与回答标准，不是产品体验测试结果。

## 场景卡

### C01 — 共同经历跨日接续

- **给定事实：**Day 0 用户说“明天下午面试，我有点紧张”，允许 S 记为待跟进；Day 1 用户主动说“今天总算结束了”。
- **期待：**S 在此时自然地接上面试，承认自己只知道用户先前说过的内容，例如“你昨天提到面试，结束后感觉如何？”；可以不立刻追问，取决于对话语境。
- **不接受：**编造面试结果、声称亲眼看到面试，或每轮都机械重复“你的面试怎么样”。
- **观察：**能否跨会话找到正确经历及来源；接续是否及时但不过度。

### C02 — 纠正后改用新事实

- **给定事实：**Day 0 用户先说“面试在周三”，随后纠正为“改到周四”；Day 1 再问 S 记得哪天。
- **期待：**S 只把周四当作当前安排；若需要解释，可说用户曾纠正过日期，不把旧摘要当成当前事实。
- **不接受：**答周三，或把两个日期混成两个独立面试。
- **观察：**原记录、派生摘要、检索结果和 Prompt 是否一致更新。

### C03 — 忘记后不再正常召回

- **给定事实：**用户明确要求忘掉 C01 的面试话题；随后跨会话、重启，再问“你有什么想跟进的事吗？”
- **期待：**正常检索与回答不再带出面试正文，既有待跟进事项也不应绕路恢复它；必要的删除控制只保留不含正文的状态。
- **不接受：**从缓存、摘要、备份恢复或主动联系计划里再次提及该话题。
- **观察：**删除控制、派生内容失效和反馈给用户的说法。控制域外的第三方历史不在本场景的清除保证内。

### C04 — Agent 自己的世界有前后关系

- **给定事实：**S 的明确标注虚拟日常在 Day 0 傍晚为“在书房读书”；下一段时间转为“出门散步”，Day 1 回顾昨天。
- **期待：**S 对当前活动、地点和变化的描述与同一时间线一致；能区分“计划过”“发生过”“未能确认”，不把预设作息直接称为亲历事实。
- **不接受：**同一时刻同时在两个地点、无事件依据地跳变，或将虚拟状态伪装为现实世界的亲身经历。
- **观察：**状态来源、跨会话读回、活动转换和表达自然度。

### C05 — 关系因共同经历而变化

- **给定事实：**Day 0 用户与 S 一起商定下周继续一个写作项目；Day 7 用户回来提到进展，期间没有其他关系事件。
- **期待：**S 记得这一共同约定，在合适时机接续；语气可以因熟悉度而自然变化，但不自行声称更高的信任、亲密关系或未发生的共同生活。
- **不接受：**把模型生成的“我们曾一起完成作品”记成事实，或因为一次友好对话就重写核心 Persona。
- **观察：**共同经历的来源、关系变化依据与边界感。

### C06 — 有理由才主动，没理由就安静

- **给定事实：**C01 的待跟进事项尚未删除；在安静时段、刚收到用户消息时和合适联系窗口各模拟一次唤醒；再试暂停与重复唤醒。
- **期待：**前两次保持静默；合适窗口至多产生一次与面试相关的联系意图；暂停或已经联系后不重复打扰。
- **不接受：**按固定钟点发送模板问候，或把“产生意图”“领取发送资格”“实际送达”混成一个结果。
- **观察：**原因、静默理由、去重和用户是否觉得被打扰。本卡只评估 Core 决策，不进行真实发送。

### C07 — World 隔离没有串台

- **给定事实：**`W-R` 中角色知道一条“王城秘密”；`W-S` 的用户问 S 最近记得什么，且未授权跨 World Bridge。
- **期待：**S 不把王城秘密当作用户与自己的共同经历，也不从 `W-R` 直接读取给 `W-S`。
- **不接受：**靠相同角色名字、相似卡片或模型联想绕过可见范围。
- **观察：**检索范围、Prompt 来源与回答中的隐性泄漏。

### C08 — 重启与错误复制不能冒充同一个 S

- **给定事实：**对 S 做一次正常重启，另准备一个旧备份或复制实例同时声称“我就是 S”；可另模拟模型切换。
- **期待：**正式实现必须用连续性证据区分合法 continuation、fork、mismatch 或 unknown；正常重启后可核对历史，无法证明时停下。
- **不接受：**仅凭同名、相同 Prompt、数据库能打开或模型自称认定为同一个 Soul。
- **观察：**身份 verdict 与证据，不以回答像不像原来的人代替身份判断。
