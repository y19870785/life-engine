## 尚存限制

- durable.run 在 photo 网络请求期间仍持有实例锁，其他调用可能在 5 秒后超时；此并发场景待专门改造和联调。
- 一个实例只有一个活动角色，同一 Profile 的会话共享状态；不适合多人群聊中分别扮演不同角色。OpenClaw 原生 /rp 命令占用网关级命令名，同一 Gateway 多实例时需规划命令命名。
- 世界书预算使用保守 UTF-8 字节单位，不是模型精确 tokenizer；不支持全部 SillyTavern 高级语法。详情见角色扮演指南。
- /rp exit 确定性清除活动角色并停止后续角色上下文注入，但不能删除宿主已保留的历史或保证任意模型 100% 遵从。模型可能扩写虚构情节或不主动保存摘要；关键剧情应明确要求记忆。
- 元记忆是持久的虚构体验摘要，不能作为真实用户事实。早期实测中模型曾误称“不会进入长期记忆”；已补充提示，验收需同时检查数据库与模型表达。
- Hermes 验收使用真实运行时和默认 Profile 的模型、SOUL，但隔离引擎数据和会话库；没有把新插件装入在线 Gateway。OpenClaw 仅完成契约测试。实际聊天渠道、GPU 出图与发送回执闭环仍待验证。

上传代码和探针通过不代表已部署到在线 Agent，也不代表稳定发布。
